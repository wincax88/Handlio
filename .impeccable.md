## Design Context

### Users
English-speaking independent developers, software implementation consultants and small service studios create a client handbook. Invited clients read, ask questions and confirm receipt of a specific version. Content supports Unicode, including Chinese.

### Brand Personality
Clear, considered, dependable. The user delegated visual direction to the implementer. Help creators feel in control and clients understand exactly what they received.

### Aesthetic Direction
The user selected `docs/Handlio_Interactive_Prototype.html` as the visual authority. Match its teal #0d7d77 brand, white sidebar and topbar, #f6f8f6 canvas, system sans typography, 12px cards, four-column metrics, project tables, split authentication, full-width three-column editor, and client reading with a receipt rail. Reuse the supplied logo. Preserve real data, authorization, save states and backend interactions; prototype fixtures stay explicitly illustrative.

### Design Principles
- Give version identity, save state and access boundaries a fixed visible place.
- Use plain language and explicit next actions for empty and error states.
- Separate published content from draft editing and receipt confirmation from reading.
- Keep manual creation usable when external providers are unavailable.
- Preserve keyboard navigation, visible focus, reduced motion and readable mobile content.
