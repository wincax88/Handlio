GUIDE 01 / 03

Getting started

Use your own Content editor account. Confirm that instructions fit the current system before proceeding.

1Use your own invited account

Open the admin address provided separately by your project contact. Use your own invited account; no shared passwords belong in this handbook.

Expected result: You are signed in and see the admin navigation.

2Check your role

Confirm that your Content editor role has permission to edit pages and media. Ask the project contact if a required section is missing.

Expected result: Pages and Media are available for your account.

3Prepare your approved content

Keep the approved replacement text and images ready. Do not include confidential customer records or personal data in public content.

Expected result: The approved assets are ready before you start editing.

GUIDE 02 / 03

Update website content

Use your own Content editor account. Confirm that instructions fit the current system before proceeding.

1Open the pages list

In the admin sidebar, choose Pages. Find Home and select Edit.

Expected result: The Home page editor is open.

2Update the page heading

In the Hero heading field, replace the current heading with the approved copy. Keep the rest of the page unchanged.

Expected result: The new heading is visible in the editor; the live site is unchanged.

3Save and preview

Save the draft, then open Preview. Check the heading, line breaks and page appearance.

Expected result: The preview shows the intended change.

4Publish the reviewed page

Only publish after the preview has been checked. Confirm the page you are publishing is Home.

Expected result: The reviewed page is published.

5Check the live result

Open the public page and confirm the final text. Report unexpected behavior to your project contact rather than making unrelated changes.

Expected result: The public page displays the approved heading.

GUIDE 03 / 03

Manage your media

Use your own Content editor account. Confirm that instructions fit the current system before proceeding.

1Prepare the replacement image

Use the agreed image dimensions and a licensed image. Remove private metadata before uploading.

Expected result: The replacement image is ready to use.

2Choose the correct asset

In the page editor, locate the cover image you need to replace. Check the page and image label.

Expected result: You have selected the intended page image.

3Add an accessible description

Upload the replacement and add alternative text describing its relevant content. Do not put private details in the description.

Expected result: The selected image and its alternative text are ready to preview.

4Preview and publish carefully

Check crop, legibility and mobile appearance in Preview before publishing. Keep other assets unchanged.

Expected result: The image appears correctly in the published page.
