# 非支付功能补齐

本批次完善现有非支付能力，支付订单、结账、退款和对账逻辑保持原范围。
验证已通过：51 项服务端测试；Chromium、Firefox、WebKit 共 21 条完整浏览器流程；类型检查及生产构建。200 步 Unicode 手册和长截图导出、加密恢复与篡改拒绝都有专门测试。跨浏览器回归还修复了迟到的加载响应覆盖编辑的保存时序问题。

| 能力     | 完成内容                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 工作台   | 生命周期、方案、确认状态组合筛选，80% 存储预警；当前版本的有效阅读人数与确认分开显示                                   |
| 项目复制 | 显式选择已审核图片，复制为新项目独立的扁平图片；不复制客户、邀请、订单或确认记录                                       |
| 图片标注 | 已遮盖底图与标注配方分离；跨会话编辑位置、尺寸和标签；新配方生成新图片，已发布图保持不可变                             |
| 导航保护 | 未上传素材在内部链接和浏览器后退时提示；关闭页面保护继续有效                                                           |
| 术语     | 最多 30 个首选术语及别名，编辑器提示别名和大小写差异；不会自动替换客户说明                                             |
| 质量检查 | 截图小字启发式提示、修订绑定的外部 HTTPS 链接检查；受限、超时和 IPv6-only 链接要求人工复核                             |
| 安全事故 | 关联标注底图及派生图隔离，保留事故记录，向受影响的有效客户发送无敏感内容通知；关闭事故不恢复共享                       |
| AI 预算  | 项目美元预算、服务每日总上限、逐次预留、实际／未知费用分开计量；超价或连续失败自动暂停，近期验证后审计恢复             |
| 导出保护 | 无供应商凭据的独立进程，Node 堆 256 MiB、180 秒硬限制、取消时终止进程树；失败释放导出额度                              |
| 恢复工具 | AES-256-GCM 加密快照，逐文件散列与 SQLite 完整性校验，拒绝篡改、危险文件名及覆盖现有目录；旧会话失效、临时导出重新生成 |
| 运营     | Worker 心跳、备份失败和 AI 暂停的诊断元数据；可配置每日加密备份及最多 35 天轮换                                        |
| 服务信息 | 运营主体 Handlio Team，所在地中国大陆；托管地区未确认时明确显示待确认；披露应用已实现的清理时间                        |

标注底图只含已完成安全处理的像素，客户不能通过配方接口访问底图。安全撤回同时隔离同项目关联图及其引用版本。项目复制得到独立的扁平图片，源项目撤回不会跨项目自动撤销这些经过显式复核的复制品。

AI 适配器须遵守请求的 `maxCostUsd` 和 USD 计量约定。未提供可靠费用时保持保守预留；超时或调用失败不被猜测为零费用。真实 AI 账户和处理协议需要另外配置，预算功能不会自动启用模型。

链接检测不携带登录 Cookie 或供应商凭据，固定连接到经过检查的公网 IPv4 地址；每次最多 20 个链接。截图小字提示是可读性启发式判断，不等于 OCR 或敏感信息检测。

## 外部待确认

- 实际数据托管地区、托管／邮件／AI 供应商的保留条款及正式经营政策。
- 生产备份密钥、独立备份存储和异地复制，以及备份后的撤权／删除清单在生产恢复时的核对。
- 真实 AI 凭据、模型质量样本与准确供应商成本。
- 真实 macOS Safari、设备和实际客户邮箱的人工验收；WebKit 自动化不是 macOS Safari 实机验收。

不把本地加密恢复演练视为生产 RPO／RTO 或异地恢复承诺。
