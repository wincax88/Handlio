# HTML 原型设计对齐

视觉参考为用户提供的 `Handlio_Interactive_Prototype.html`。现有应用沿用其品牌图标、青绿色、白色导航、卡片、表格、无衬线文字和页面分区。业务仍由真实 API、关系数据、权限和版本快照驱动，未复制原型 JavaScript 中的模拟支付、模拟验证和样例工作区数据。

| 原型页面        | 对应应用                                    | 主要调整                                                               |
| --------------- | ------------------------------------------- | ---------------------------------------------------------------------- |
| 官网首页        | `/`                                         | 双栏介绍、手册/CMS 例图、双入口、三个制作阶段和导出说明                |
| 定价与示例      | `/pricing`, `/examples`, `/app/examples`    | 三种项目报价、独立模板示例、真实工作区入口                             |
| 邮箱登录/验证码 | `/auth`                                     | 左侧说明和示例，右侧验证表单，手机保留单列登录                         |
| 项目工作台      | `/app/projects`                             | 四项真实指标、托管提醒、项目表格、状态筛选、排序、待办与模板入口       |
| 项目总览        | `/app/projects/:id`                         | 草稿/发布分离提示、指标卡、指南列表、收件进度、用量与真实活动          |
| 指南编辑        | `/app/projects/:id/guides/:gid`             | 独立工具栏、指南选择和步骤卡、截图优先的编辑画布、属性及人工审核       |
| 素材遮盖        | `/app/projects/:id/assets`                  | 上传队列、实心遮盖、原型配色和控件；从编辑器进入时加载已经安全处理的图 |
| 手册组装        | `/app/projects/:id/handbook`                | 左侧章节和清单，右侧品牌/封面即时预览，指南排序与支持说明              |
| 版本与交接      | `/app/projects/:id/releases`, `/handoff`    | 卡片和状态色统一；交接页指标来自已发布版本、实际确认人数及问题         |
| 账单与导出      | `/app/billing`, `/app/projects/:id/exports` | 项目权益列表、真实订单、选定项目用量；正式购买或开发模拟仍需明确点击   |
| 客户阅读        | `/h/:id`                                    | 项目品牌栏、目录、正文和收件辅助栏；手机使用目录抽屉和收件入口         |

`src/reference-base.css` 保留并映射参考文件的样式，`src/prototype.css` 负责真实应用组件的适配和移动端差异。原始 HTML 保留不变。设计上下文也记录在项目根目录 `.impeccable.md`。

原型的固定客户、订单和活动只用于公开的明确示例。工作台的数量、托管日期、问题、订单、确认和活动均从自有项目的服务端记录获取。没有活动时显示空状态，尚未发起收件请求时不显示虚假的完成百分比。

回归包含完整创作者到客户的交接路径，以及已遮盖图片从编辑器再次处理后仍保留遮盖像素的检查。类型检查、生产构建、42 项服务端测试及 5 条浏览器回归已通过；外部供应商及完整商业上线事项沿用 `implementation-status.md`。

## 原型功能补齐

原型中的产品操作已补入真实应用：首次工作区初始化；完整公开样例与 PDF / ZIP 下载；桌面 / 手机草稿预览；字段、步骤及截图的版本差异；保留独立修改的三方冲突合并；每批 1–10 个邮箱邀请；问题状态筛选、定位、解决版本选择与客户线程回复；本人完整回执与确认时版本变化提示；工作区品牌、设备会话与通知偏好；限时支持授权；订单详情、支付状态与续期确认；导出版本 / 规格 / 截止时间及失败重试；帮助搜索；运营元数据检查、受控重试和权威付款查询。

公开样例使用原型已有的虚构 Northstar v2 附件，位于 `public/samples/`。工作区 Logo 只从已安全处理的项目素材选择，新项目复制为自己的素材。临时支持授权只允许诊断元数据或用户另外提供的脱敏文字，不赋予手册、截图或代登录权限；到期和撤销由 API 执行。

浏览器回归使用独立的 5183 / 3011 端口和 `.work/e2e-data`，强制本地邮件 / 付款模拟，关闭 AI。覆盖初始化、样例下载、设置持久化、授权撤销、手机预览、三方合并、字段差异、批量去重、客户回复、版本竞态、完整手机回执、续期勾选与运营操作。`design-system` 和 `sitemap` 保留为原型评审资源，不是生产导航。

真实供应商账户、支付及 AI 适配器部署、发信域名与实际投递、正式经营政策和生产恢复验收仍是外部上线事项，不以本地通过测试代替。
